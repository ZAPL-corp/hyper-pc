## Сборка
Установите последнее обновление проекта через `Code` -> `Download ZIP`
Проверьте наличие установленного .NET 11 командой `dotnet --version`
Откройте CMD в папке (в адресной строке проводника введите cmd, или Shift + ПКМ по пустому месту -> `Открыть в CMD`) 
и введите следующие команды:
```bash
dotnet build
dotnet run
```
Всё вы получили полный открытый код настольного Windows / Linux приложения
